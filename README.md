# Call-Centre-Operations-Analytics-Dashboard
This project presents an interactive Power BI dashboard designed to analyze call centre performance and customer service trends. It helps stakeholders monitor operational efficiency, agent performance, and customer satisfaction.

# Objectives
Track overall call centre performance

Analyze agent efficiency and workload

Identify peak call times and trends

Measure customer satisfaction levels

Improve decision-making with data insights

# Key Insights 
Peak call volumes occur during specific hours, indicating need for better workforce scheduling

Higher average handling time (AHT) often correlates with lower efficiency

Agents with balanced workloads show better resolution rates and customer satisfaction

Unresolved or escalated calls significantly impact CSAT scores

Faster response and resolution lead to improved customer experience

# Impact
This dashboard enables organizations to:

Improve operational efficiency

Enhance customer satisfaction

Reduce call handling time

Make data-driven workforce decisions
